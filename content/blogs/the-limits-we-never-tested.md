Some limits are physical. Most are not. They are assumptions that hardened over time until nobody remembered they were assumptions.

## Two kinds of limits

- **Hard limits** — set by physics, mathematics, or resources.
- **Soft limits** — set by habit, cost structures, or the tools we happened to have.

The trouble is that soft limits *feel* exactly like hard ones.

## A simple test

When you hit a wall, ask what would have to be true for it not to exist. If the answer is "a different tool" or "a different process", the limit is soft.

```text
limit -> assumption -> experiment -> new possibility
```

## Build to find out

Thinking only goes so far. The fastest way to test a limit is to build something small that tries to cross it.
